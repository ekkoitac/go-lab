# 第 12 题：切片描述符交互设计

按《学习-知识点教学中的交互与呈现方式》区分目标、呈现与操作。目标是根据起点、长度、容量判断索引与重新切片；典型误解是把 cap 当作可索引范围或有效业务数据量。

主实验以固定六字节数组为可观察存储，用户构造合法描述符，预测并执行索引或二索引重新切片。代码、起点、len/cap 和格子同步变化。失败保留描述符并展示具体不等式；支持回退单步和重置。三索引表达式用于构造受限容量，不暗示容量永远等于底层剩余长度。

帮助四种独立交互：窗口类比调节开口/窗框；关联图移动起点并追踪相对索引；分步推导 s[1:3] 的检查、更新和读取；新日志缓冲情境先提交预测与理由再反馈。帮助独立于主实验，无掌握证据写入。

语义边界：索引用 len；重新切片 high 可到 cap；新 cap=旧 cap-low；无复制、无扩容、无数据写入。panic 只模拟，不中断页面；0 只是初始化值。以语义 JSON 暴露状态便于验证。所有控制为原生键盘可用控件，窄屏内存格子换行，减弱动画偏好无动画。

验证：纯模型测试覆盖长度边界、容量扩展、起点偏移、空末端与非法参数。专属浏览器测试覆盖预测修复、零值读取、回退重置、四种帮助、320/390px、键盘及无证据写入；由根任务统一执行浏览器测试与构建。
