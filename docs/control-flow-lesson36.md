# 第 36 题：具名返回值与 defer 的交汇点

| 设计项 | 实现 |
| --- | --- |
| 学习目标 | 解释 return 赋值、defer 修改、真正返回三个时点；根据变量身份预测调用者所得整数。 |
| 典型误解 | return 立即离开；defer 改任意局部变量都会改返回值；具名 return 7 后仍对原来的 n 运算。 |
| 核心关系 | 变量身份、整数复制、执行先后及调用边界。 |
| 呈现形式 | 代码位置高亮、时间线、局部变量/返回槽/调用者关系图、两种签名同步对照。 |
| 交互任务 | 改初始值、return n 或数字、defer 加法/乘法和操作数；单步、回退、重置；点击对象追踪位置关联。 |
| 模型与反馈 | 纯函数按阶段重建整数状态；return 写入结果槽；只有具名 n 与结果位置同一；defer 完成前调用者始终未收值。 |
| 帮助方式 | example 是签核报表的可执行类比；diagram 点击对象并跳转阶段追踪关系；steps 是可回退教程；try 新输入预测两个结果并写理由后验证。 |
| 独立验证 | 帮助练习不记录独立掌握成绩；理由供自查不自动评分；原有独立测验不变。 |

边界：一次 defer、整数值、无指针共享或 panic。匿名返回槽是辅助示意；具名图的 n/返回槽是同一变量的两种角色，不是独立存储。示例类比不代表 defer 提供发送或事务保证。

输入范围 -99 至 99；乘法结果无需限制为输入范围。值为零时明确显示零，不能误显示“尚未返回”。修改输入重置过程；切换签名保留同一观察阶段。

验证：node --import tsx --test tests/control-flow-lesson36.test.ts。覆盖复制/别名、具名结果先赋值、时点、零/负数/无值变化操作、回退及输入边界。CSS 支持窄屏纵排、键盘焦点及 reduced-motion；状态反馈 aria-live。
