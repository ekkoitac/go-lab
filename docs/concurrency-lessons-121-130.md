# 121–130：并发与生命周期教学实验

依据用户指定的《学习：知识点教学中的交互与呈现方式》，每题由独立子代理实现，主代理负责接入、审查和浏览器回归。

## 设计与责任边界

先明确学习目标，再选择呈现与操作。操作必须改变模型或提交预测，结果需解释因果；单纯展开说明不作为掌握证据。模型均为确定性教学模拟，不是 Go 调度器或生产性能实测。

| 题号 | 要理解的关系 | 操作与观察重点 |
| --- | --- | --- |
| 121 | 执行、goroutine 与队列是不同资源 | 同批任务比较直接启动、内部许可和固定 worker；调整容量，追踪等待位置 |
| 122 | 排队、重试与组装共享端到端预算 | 改变并发额度与耗时，比较继承 deadline 和局部重置 |
| 123 | 业务关键性决定失败传播 | 切换失败节点和必需/可选，追踪取消信号与实际退出 |
| 124 | 取消、收尾、完成、资源关闭有依赖 | 构造退出顺序，观察收尾能否访问资源及等待预算 |
| 125 | 总容量限制不等于租户公平 | 调度各租户队列，比较 FIFO/轮转与任务成本 |
| 126 | 接收确认意味着责任交接 | 满队列下选择等待/拒绝/允许丢弃，追踪真实接收结果 |
| 127 | 所有权与整体版本决定同步边界 | 读写交错、整体发布，观察旧读者和嵌套对象别名 |
| 128 | 锁等待来源与写回校验 | 移出慢 I/O、分片和热点干预，比较等待与过期写回 |
| 129 | 字段原子性不等于整体一致性 | 安排读写交错，对比分字段、多次 Load 与一次快照 |
| 130 | 请求、服务与持久任务生命周期不同 | 改变上下文继承、期限和退出事件，观察取消与关联信息 |

- 10 个独立子代理分别完成 121–130，每题独立组件、纯模型、样式、模型测试；主代理接入和复核。
- 新增模型测试 64 项；全仓 `npm test` 共 618 项通过，0 失败、0 跳过，含真实 Go 运行器验证。
- `npm run build` 通过：TypeScript、200 课 / 1200 题内容完整性、Vite 生产构建。已有 Mermaid/ELK 大包体提示仍存在，本次无打包错误。
- 生产构建浏览器验证 34 项通过：十题在 1440px 与 390px 下的 20 项验证、121 专项 5 项、122–130 关键行为 9 项。
- 验证包含预测前置、单步与精确回退、参数更改重开、修复后结果、四帮助切换、键盘、减少动态、页面/面板溢出与正式学习记录隔离。
- 截图保存在 `.runtime/concurrency-labs/`，构建日志在 `.runtime/concurrency-build.log`，全量测试日志在 `.runtime/concurrency-all-tests.log`。
- 最终浏览器验收使用 `http://127.0.0.1:28318` 和 `.runtime/concurrency-production-data`；开发服务首次冷启动曾导航超时，改用预热服务后通过，再以生产构建完整复验。

这些实验是可操作的教学模型，不能替代真实 Go 调度测试或生产性能测量。未修改原有正式测验、编辑器、课程答案和数据格式。
