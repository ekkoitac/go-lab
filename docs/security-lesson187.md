# 第 187 题：网络、身份、接口权限

学习目标：区分可连接、可验证主体和获准动作；用同网段反例、自报头反例和有效身份越权反例解释为什么三个检查不可互相代替。

呈现与交互：三层状态流 + 同输入策略对照；参数操控、先预测并写理由、单步、回退、重置与反事实比较。修改输入清空推演和预测，尚未执行时不呈现最终结果。认证成功后暂停，权限保持未执行。

四种帮助：园区工牌类比可改工牌和房间；关联图可改网络/证书/主体/动作并高亮依赖关系；过程帮助逐关检查；迁移练习使用跨集群第三方服务，提交预测理由后反馈。帮助状态不进入 progress、attempt 或 reveal。

模型：网络策略 → mTLS 客户端证书与可信主体映射 → 主体/动作策略。订单服务可读取和预留；第三方仅可读取；普通 Pod 无库存权限；三者都无管理权限。自报 X-Service 不参与身份建立。非可信、过期或缺失证书拒绝，单向 TLS 模式没有配置额外客户端认证。

边界：服务端证书假定可信；证书有效意味着模型已完成信任、有效期、持钥和身份绑定校验。未模拟真实密码学、签发轮换撤销、控制面故障、代理转发或密钥泄露。无生产权限推荐的自动推导。

验证：10 个 Node 模型测试覆盖三层短路、相同身份不同动作、凭据错误、请求头不可冒认、第三方最小权限、不可变回放与全部输入组合的不变量；浏览器规格覆盖预测门槛、分层状态、回退重置、条件切换和 320px 不溢出。
