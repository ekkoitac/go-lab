# 第 21–30 题：类型、结构体、接口与泛型

设计依据：`E:\ekko-lib\ekko-lib\临时\学习-知识点教学中的交互与呈现方式.md`。先确定学习目标，再选择能表达知识关系的视图和能检验想法的操作。每题由一个独立 subagent 实现；共享入口和集成验证由主任务完成。

| 题号 | 关键关系 | 动手任务与视图 |
| --- | --- | --- |
| 21 | 方法集与可寻址性 | 修改接收者来源和调用入口，预测后追踪检查路径；对照直接调用、接口赋值与 map 副本写回 |
| 22 | 字段值与共享引用 | 修改数量、写标签元素、重新绑定和按需复制；从对象关系图追踪原订单受到的影响 |
| 23 | 嵌入深度与选择器唯一性 | 构造同层歧义、嵌套深度与外层遮蔽；沿字段树验证显式路径 |
| 24 | 接口动态类型与动态值 | 装入 typed nil、nil 接口或真实对象；观察双槽、分支与方法调用结果 |
| 25 | 类型身份与安全失败 | 调整动态载荷与断言形式，验证类型匹配、零值和 panic 路径 |
| 26 | 动态类型与分支路由 | 构建分拣分支、检查未知类型与 nil 边界，修复静默成功 |
| 27 | 使用方需求与方法集合 | 调整所需能力和提供者，比较过大契约、最小契约和业务完整性 |
| 28 | 静态可比较与动态风险 | 比较不同动态类型的相等/键操作，修复切片键并检验边界 |
| 29 | 约束类型集与可用操作 | 调整类型集合，分别检查函数体运算和调用准入；观察命名类型与 ~ 的关系 |
| 30 | 类型关系与共同行为 | 对比同类型参数、异构 Sender 队列与组合方案，检查数据流与调用结果 |

四种帮助分别提供类比或实例、可操作关系图、分步推导和新情境练习。辅助练习显示预测与理由，揭晓后提供具体差异和下一次尝试方向；不会调用正式答题/揭晓接口，也不会将辅助结果写为独立掌握成绩。帮助使用独立组件状态，打开或关闭不会改变主实验。

实现位于 `src/components/types-lab/lesson21` 至 `lesson30`，按题懒加载。模型是假设明确的教学模拟；编辑器继续承担真实 Go 执行。原课程题目、正式评分和持久化协议保持现有逻辑。

验证覆盖：纯模型语义、四种帮助和主实验隔离、桌面与 320px 窄屏、减少动态效果、无正式成绩写入，以及关键操作的浏览器流程。Go 1.26.1 已完成 21–30 题原例/修复/测试共 30 项核对。
