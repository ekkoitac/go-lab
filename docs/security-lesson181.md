# 第181题：认证与资源授权

学习目标：解释可信身份、租户归属、角色动作权限为何都是必要条件；构造登录成功但越权的反例；区分客户端自报角色与可信主体。

动手观察提供六个可控输入：身份来源、主体租户、订单租户、可信角色、动作、自报角色。先提交结果预测和理由，再单步经过身份、租户、动作、业务执行；对照相同输入下仅检查登录的策略。订单原始、已更新、已删除状态来自模型；拒绝后的检查明确跳过。回退可撤销执行，修改输入开启新的预测实验。

四种帮助分别为：分馆档案类比的可操作闸门；角色动作矩阵与租户连接联动；同租户读者修改订单的逐步实验；发票、库存、报表的新情境预测反馈。所有帮助使用局部状态，不调用进度、测验或答案揭晓接口。

模型沿用课程代码权限：reader 可 read；editor 可 read/update；未知角色和未知动作默认拒绝；没有删除授权。可信身份来自输入假设，不实现令牌签名验证、数据库并发、角色继承或跨租户管理员例外。探索与有反馈的迁移练习不作为课程独立掌握证据。
