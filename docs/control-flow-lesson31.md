# 第 31 题：range 元素副本

| 设计项 | 实现 |
|---|---|
| 学习目标 | 追踪普通字段复制、下标写原存储、指针字段共享目标三种写入落点 |
| 典型误解 | item 是原元素别名；所有副本字段都隔离原数据 |
| 呈现形式 | 原切片、迭代副本、共享整数三列内存图与循环体联动 |
| 动手观察 | 编辑原价和折扣；切换策略；复制/执行分步、回退、重置 |
| example | 同一输入并排运行副本与下标折扣，比较原切片合计 |
| diagram | 选择写入落点并执行/撤销；点击存储卡关联复制与引用关系 |
| steps | 扮演 range，检查复制、写入、下一轮，可回退 |
| try | 仓库新情境先提交价格、库存与理由；揭晓后换情境复测 |
| 反馈 | 每步指出操作、具体数值变化、未变字段和原因 |
| 模型边界 | int 折扣截断；Price 与 *int Stock；每项库存独立 |
| 独立验证 | 提交前不渲染答案模型；理由仅自查；不记课程成绩 |
| 可访问性 | 原生表单及按钮，aria-live，320/390px堆叠，reduced-motion |

测试：npx tsx --test tests/control-flow-lesson31.test.ts。
