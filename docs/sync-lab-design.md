# 第 41–50 题：并发与同步交互实验

依据用户指定的《学习：知识点教学中的交互与呈现方式》，把每题的目标、操作、证据与模型边界分别实现。

| 题号 | 学习者操作 | 可观察证据 |
| --- | --- | --- |
| 41 | 安排主任务返回、后台写入、完成通知 | 启动、写入、回执、退出四种状态 |
| 42 | 分配单/双执行单元的时间片，改变工作量 | 相同总工作量下的交错与并行时间线 |
| 43 | 安排两任务读、加、写，切换整段加锁 | 本地快照、共享计数、锁范围、丢失贡献 |
| 44 | 调整转账金额，在扣款与入账之间读取 | 内部中间总额与监控可见快照的区别 |
| 45 | 获取/释放各对象的锁，检查访问权 | 同一数据对应两把锁或同一锁的引用关系 |
| 46 | 决定哪个任务申请哪把锁，比较锁序 | 持有、下一次请求、实际阻塞与等待环 |
| 47 | 释放读锁，在空隙注入其他写者，再复查 | 自我阻塞、读者计数和已有缓存保留 |
| 48 | 登记任务、调用 Wait、逐份 Done | 已启动、已登记、已完成的区别 |
| 49 | 逐个处理请求，改变 Once 的包围范围 | 初始化次数与业务次数的差异 |
| 50 | 在版本与阈值更新间插入读取 | 混合版本、整体锁等待和一致快照 |

共用操作：执行前文字预测、变化前后值、可回退时间线、回退后分叉、参数重置、保留快照作对照。参数不同会明确提示，且保存快照注明操作时点。文字预测仅供自评。

## 换个方式理解

- 举例子：逐项映射生活对象与程序对象，说明类比边界。
- 画图：使用独立 SVG 图解，按知识关系分别绘制生命线、时间片网格、共享内存流向、转账余额与锁边界、锁对象引用、等待环、读写锁流程、登记数量、Once 范围和配置快照。支持逐帧、条件对照及键盘选择节点并高亮关联连线，不嵌入自由实验台。
- 拆步骤：逐步执行明确的因果路径；展示下一操作，并可回看。
- 让我试试：先预测并记录理由，提交后才展示答案和实际模型轨迹；切换另一组条件再次练习。仅有两组条件交替出现，明确提示重复练习不算新独立证据。

沿用既有求助记录接口；帮助练习不向正式作答接口提交成绩，不改编辑器内容。课程数据版本、正式测验与后端均未变更。

## 实现与验证

- `src/components/sync-lab/model.ts`：无副作用的状态转换、操作合法性、观测值与关系。
- `guides.ts`：十题目标、操作说明、边界、引导路径与验证题。
- `SyncLab.tsx`：主实验及四种帮助方式；CSS 独立且按需加载。
- `tests/sync-lab.test.ts`：12 组模型测试，含第 43 题所有合法调度、非法操作、边界、快照不可变及练习答案对照模型。
- `tests/browser/sync-lab.spec.ts`：十题两种条件、四种帮助方式、预测与回退分叉、编辑器隔离、键盘、390px 与减少动画偏好。
- 第五章原有静态帧浏览器测试由新状态模型测试替代；其他章节仍走原有测试。

本地验收：独立端口 17317/17318，独立数据目录 `.runtime/sync-lab-e2e-data`。这些是教学模型，非实际 Go 调度器、race 检测或性能测量；每题界面都标明具体简化。


验收结果（2026-10-17）：完整构建和课程完整性检查通过；全量测试 81 项通过；等待环与 Wait 顺序细化后，12 组专用模型测试及 7 组浏览器回归再次通过。已人工查看桌面等待关系与手机缓存复查截图。

独立图解验收：SyncDiagram.tsx 与 diagrams.ts 负责十题的 SVG 图形；4 组图形语义测试及原 12 组模型测试通过。3 组专用浏览器测试逐题遍历两种条件的全部帧，覆盖 1440px / 390px、节点文字边界、连线标签重叠、键盘选择及等待环；最终构建通过。
