# 第 151 题：剩余时间与取消传播

学习目标：从当前剩余时间分配串行预算，区分 deadline、取消信号与 I/O 实际停止。

动手观察提供总期限、已用时间、回包预留、两个调用耗时、预算策略、父 context 继承和取消响应开关。每次修改参数重建轨迹并回到起点。事件可单步、回退、重置；状态展示绝对时钟、子预算、子截止、父状态、下游占用、取消送达与无用工作。

四个帮助入口：
- example：同输入下独立 1000ms 与共享预算的事件对照。
- diagram：可断开的父子 context 关系；选中父、子、I/O 联动代码和数值解释；耗时可调。
- steps：独立局部状态的单步实验，支持参数调整。
- try：三组新输入轮换；先提交预算、取消结果和理由，再运行揭晓，不写成绩或进度。

模型为确定性串行毫秒模拟；共享预算是 (总额 − 当前已耗 − 回包预留) / 剩余步数，取整且不小于零。取消响应假定立即释放。完成与到期同刻时采用到期优先，仅为确定性教学约定。独立子超时依然生效，即便父取消没有传播。无用工作指标是请求/子调用已失败之后继续占用的毫秒数，并不只计父 deadline 之后。

接口：default Lab 无 props；Help({mode:string}) 接收 example/diagram/steps/try。根 testid resilience-lab-151 / resilience-help-151，模型 live-model 的 data-state 为 JSON，单步按钮具有 data-resilience-action。

验证：tests/resilience-lesson151.test.ts 覆盖预算重算、取消丢失、忽略取消、独立子超时、预算耗尽和事件快照；浏览器测试覆盖单步、回退、参数重启、重置与 390px 宽度。
