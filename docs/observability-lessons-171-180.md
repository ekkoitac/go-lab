# 171–180：可观测性与可靠性实验

设计依据：`E:\ekko-lib\ekko-lib\临时\学习-知识点教学中的交互与呈现方式.md`。

每题由一个独立 subagent 实现模型、观察视图与四种帮助。共享入口仅负责按课程 ID 懒加载，不共享教学状态；探索和帮助不会写入正式作答或独立掌握记录。

| 题目 | 要理解的关系 | 呈现与操作 | 关键边界 |
| --- | --- | --- | --- |
| 171 支付 SLO | 受理、成熟窗口与及时终态 | 支付事件时间线、统计口径对照与预测 | 未成熟不能提前判失败，HTTP 成功不等于旅程成功 |
| 172 预算燃烧告警 | 分母、允许错误率与持续消耗 | 调整窗口证据、长短窗对照、决策验证 | 无流量不等于健康，教学阈值不是通用生产配置 |
| 173 慢请求证据 | 聚合趋势、调用耗时与原因 | 重试时间线、请求与日志关联、证据诊断 | 缺失采样不证明请求不存在 |
| 174 指标基数 | 标签组合与增长上界 | 路径分类、标签集合与多维数量对照 | 模板化不能抵消无界租户标签；未知路由也须有界 |
| 175 上下文传播 | 值传播、消息边界与取消生命周期 | 请求、队列、消费者状态图与事件操作 | 关联不是授权；消息需显式携带元数据 |
| 176 Trace 采样 | 采集成本、结果偏置与汇聚容量 | 同批请求对照、缓存与丢弃过程 | 尾采不能恢复头采已丢弃的数据 |
| 177 goroutine 泄漏 | 阻塞、取消通知与退出证据 | 发送者状态、接收者退出、取消与完成操作 | cancel 返回不证明 worker 已退出 |
| 178 线上 profiling | 入口暴露、授权与采集预算 | 访问路径、策略调整与诊断请求模拟 | 内网不是授权；采样有时长和并发成本 |
| 179 故障时间线 | 墙钟排序与因果偏序 | 时钟偏移、消息/版本关联与证据重建 | 未知顺序保留未知，不改写原始证据 |
| 180 故障演练 | 注入范围、停止条件与恢复 | 实验组/对照组、有限步注入与恢复验收 | 撤销注入不代表系统已恢复；教学模拟不执行真实故障 |

## 模块与验证边界

- `src/components/observability-lab/lesson<ID>/`：逐题纯模型、视图和作用域样式。
- `ObservabilityChapterLab.tsx`：主实验与帮助的独立懒加载入口。
- `tests/observability-lesson<ID>.test.ts`：逐题因果、数学或状态转换边界。
- `tests/browser/observability-labs.spec.ts`：1440px 与 320px 下的加载、四种帮助差异、可读区域、原实验状态保留、编辑器/决策草稿保留、无正式作答请求。

浏览器验证使用专用端口、数据目录和输出目录；不会使用学习者的进度数据库。帮助中的练习属于辅助练习，正式独立证据仍由“迁移与复测”产生。更换情境可以再次尝试，不把已揭晓题目的反复点击当作独立掌握。
## 实现与验收记录

- 每题独立目录与纯模型；观察入口仅覆盖 171–180，帮助按四种模式分别挂载。
- 十题关键交互覆盖：成熟分母、长短窗告警、Trace 缺失、标签去重、消息关联、头采不可恢复、cancel/done 分离、诊断授权、因果证据与恢复验收。
- 50 项逐题模型测试通过；类型检查、200 课内容完整性检查和生产构建通过。
- 浏览器使用独立构建快照、端口和学习数据库，避免其他并行课程开发的热更新干扰。截图输出位于 `.runtime/observability-171-180/`。
- 实验和帮助共用作用域内深色表面，保证浅色图表文字对比度；不会改变课程外壳配色。支持 320px、键盘操作和减少动态效果偏好。
- 第 178 题区分未揭晓迁移与解析后复习；第 180 题帮助采用协议修复，主实验采用不同的消息恢复迁移题。
- 浏览器验收：30 项全部通过（10 项逐题关键交互 + 20 项桌面/320px模块与四帮助检查）；涵盖 40 个帮助视图在两种宽度下的呈现。
