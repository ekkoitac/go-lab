# 153 · 多层重试放大

学习目标：把嵌套调用树与乘法对应；区分完全失败上界、提前成功的实际次数；以单层重试归属修复放大并解释恢复机会的代价。

动手观察使用逐次底层尝试、回退、参数干预、单层预算修复与原方案对照。调用树显示网关 / 服务 / 客户端路径、失败 / 成功 / 跳过叶子，计数和因果解释同步。次数都包含首次，参数变化开启新一轮。

帮助分别提供相同故障序列下的双方案对照、点击网关子树与修改客户端分支数的公式联动、2×2×2 的独立过程、2×3×2 新情境的预测和理由后揭晓。帮助和主实验状态隔离；文字解释供自查，不声称已机器判分或正式掌握。

模型边界：同步顺序嵌套，每次失败都可重试，成功立即逐层返回，未建模并发、网络时延、deadline、退避或幂等性。第 N 次成功是受控故障序列，不表示真实恢复概率。预算不足时会失败，修复并非成功率无代价提升。

验证：`npx tsx --test tests/resilience-lesson153.test.ts`；专属 Playwright 用例覆盖单步 / 回退 / 修复 / 成功停止 / 预测门槛与 390px 布局。全部控件原生支持键盘，无自动播放，支持减少动态效果。
