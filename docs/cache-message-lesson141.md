# 141：缓存位置、失效传播与权威边界

依据用户指定《学习-知识点教学中的交互与呈现方式》：目标是预测跨进程读价、解释缓存层级中的陈旧来源，并构造“短 L1 TTL 必然足够”的反例。

- 呈现：独立 L1 / 共享 L2 / 权威库拓扑、价格与过期时刻、读取来源与调用计数联动；黄色表示值 100，不单凭颜色判错，以与权威值比较及文字反馈判定。
- 交互：先提交 t=6 的预测与理由，再单步执行更新、失效、A/B 读取、订单校验与自然过期。回退可追踪因果，回到起点可换配置；重置恢复题目基线。
- 帮助：example 切换可变价格与不可变版本键，diagram 操纵广播到达并改变读取路径，steps 执行更新协议并联动三个存储值，try 构造短 TTL 从陈旧共享层回填的反例。四种帮助分别承担情境迁移、路径探索、过程执行、预测诊断。
- 模型边界：所有预热在 t=0；DB 更新及所选失效在 t=1 顺序执行；L1 TTL 可选 3/60 秒，共享 TTL 固定 60 秒，过期采用 expires <= now。共享失效可丢失，L1 广播可漏 B。没有网络耗时和并发竞态，不把本轮观测当生产最坏陈旧上界。未模拟在途旧值回填的版本防护，不声称真实吞吐或延迟。
- 内存指标为每个 L1 配置 200 MB 的总预算，不代表当前商品对象占用。A、B 为代表实例；扩容只改变预算，不假造全体实例观测。
- 练习和帮助只有组件局部状态，不改正式测验得分；帮助后重试不作独立掌握证据。
