# 第 185 题：输入与解释器边界

依据《学习-知识点教学中的交互与呈现方式》组织对照比较、预测验证、单步回退、关联探索和新情境修复。学习目标是辨认输入在 SQL 值、SQL 结构、shell 文本及目标程序选项之间的去向。

动手观察把同一份原始输入送到拼接与受控两条路径。必须先提交预测和理由；四个阶段依次接收、构造、解释、核对。回退保留输入和预测；重置保留条件但清空推演；改变条件使旧预测失效。SQL 值保留引号、Unicode 和空格；排序选择仅映射“时间”和“名称”；命令固定为支持 -- 的 cat，并允许拆除选项边界来观察差异。

四类帮助各有独立状态：印刷店正文袋类比切换数据去向；关联图选择上下文并追踪接收者；步骤帮助单独推演 cat 的 -n 参数；迁移练习使用 --help 文件名和未知金额排序，先预测理由后揭晓，并允许具体修复。

模型只显示结构与数据身份，不执行 SQL、进程或文件读取，不是安全解析器或生产漏洞检测器。直接拼接的 structure 结果表示缺乏结构隔离，不证明所有输入都可利用。SQL 参数绑定不赋予业务权限；列名不作为普通值参数绑定。cat 的 -- 约定不适用于所有程序；文件访问权限、NUL 参数校验、目标程序其他特殊语义不在本模型覆盖范围。

所有帮助和模型状态保存在组件内部，不写入 progress、attempt 或 reveal。外层既有帮助按钮仍按应用既有逻辑记录求助。
