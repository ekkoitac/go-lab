# 第 15 题：接收 append 返回值

依据用户指定的《学习-知识点教学中的交互与呈现方式》：先确定函数边界上描述符复制与元素共享的学习目标，再组合代码执行、描述符卡片、数组格子；交互采用调参、单步、预测验证、诊断修复和新情境迁移。

## 动手观察

- 初始 cart=[7]，切换容量 1/3，控制是否返回、是否接收，以及 append 后是否修改首元素。
- 六个可回退状态：初始化、复制参数、局部 append、已有元素写入、函数返回、调用者处理结果。
- 在 append 之前提交最终 len 与首元素预测及理由；第一次验证后保留记录，不把回退当作独立答题。
- 描述符与数组同时展示；高亮调用者可访问格子。即使数组有新增元素，调用者旧长度仍为 1；容量够时已有元素写入会共享。
- 修复按钮接通 return 与赋值两段通道，清空旧预测并从起点重新观察。

## 换个方式理解

- example：仓库与两张通行证，分别操作存货、换证、共享首格修改，区分物理内容和可见范围。
- diagram：停在返回边界，选择调用者/返回结果以联动高亮数组范围；切换容量比较同数组异长度和不同数组。
- steps：逐段补全返回类型/return 与调用处赋值，单步查看只有返回仍失败的证据，再修复第二段。
- try：新情境为 helper 返回较短切片；独立预测长度并解释。未提交不渲染或序列化结果；换题重新隐藏，不写正式成绩。

## 模型边界与验证

模型仅模拟整数切片、顺序调用，不模拟实际地址、栈堆位置、GC。新分配 B 只显示 cap ≥ 2；数组格子保留作为历史证据，不表示可达性。没有返回值时禁止选择调用处接收，避免生成不合法 Go 代码。

模型单测覆盖共享元素/独立长度、扩容、返回与接收组合、回退、隐藏迁移反馈。浏览器专属用例覆盖预测门槛、修复完整路径、四个帮助模式和 320/390px 内部宽度。所有操作使用原生按钮/表单可键盘访问，保留焦点样式并支持 reduced-motion。
