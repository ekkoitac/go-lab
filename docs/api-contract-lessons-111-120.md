依据：`E:\ekko-lib\ekko-lib\临时\学习-知识点教学中的交互与呈现方式.md`。

## 教学与操作约定

每题独立维护纯状态模型、主实验和四种辅助理解视图。操作必须改变可观察的字段、路径、队列、结果或资源状态，反馈连接操作、变化与原因。主实验可直接探索，也可先填写预测与理由；辅助挑战先提交再揭晓。示例、提示与重试不产生正式独立掌握证据。

- 举例子：使用不同场景，通过改变条件观察因果差异。
- 画图：通过选择或操作关联对象，追踪契约、状态或数据关系。
- 拆步骤：支持前进、回退、重置，呈现输入、判断与状态变化。
- 让我试试：至少两个新情境，提交判断与理由后显示差异和改进建议；理由供自查，不做自动语义评分。

主实验和帮助状态独立。配置改变后清除失效结果，回退后的新操作不保留旧未来。各实验均为离线确定性教学模拟，逻辑步数、时间预算和队列单位不是生产性能实测。模拟的持久存储只解释协议，不产生真实跨进程持久化保证。

## 逐题学习目标与边界

| 题号 | 学习目标及操作证据 | 典型误解与模型边界 |
|---|---|---|
| 111 | 按客户端能力和等待需求选交互；观察请求、交接与返回过程 | HTTP 也可以创建异步任务；协议不是性能排名；接收不等于完成 |
| 112 | 修改领域字段与公开映射，检查响应字段集合 | DTO 必须正确维护白名单；错误映射仍会泄漏，客户端隐藏不能防泄漏 |
| 113 | 区分字段存在、null 与实际值，追踪更新意图与结果 | null 清空是本题约定；空字符串设置与清空结果可同而意图不同；错误不更新 |
| 114 | 调整读者、写者部署顺序，观察消费和重试积压 | 结构可解析不代表语义兼容；安全未知态必须有明确处理，不是吞错 |
| 115 | 沿错误包装链分类并映射公开响应 | 展示文案不等于错误身份；文本包装会丢失可遍历原因；公开错误不泄漏诊断 |
| 116 | 在翻页间增删记录，对照位置和稳定排序边界 | 游标不是时点快照；实时后续记录仍可能出现；本模型按唯一稳定 ID 排序 |
| 117 | 丢失成功响应后重试，对照账本和去重记录 | 同键必须同意图；新键不是同一次请求；分离写入存在崩溃窗口 |
| 118 | 关页重开、丢通知、查询和取消，观察任务与客户端两种状态 | 接收、完成、收到通知不同；关页不是取消；查询和下载必须有授权边界 |
| 119 | 改生产/消费速率与缓冲，观察积压、背压、断开续读和释放 | 缓冲不提高消费者吞吐；重放依赖保留日志；过期游标不能无损恢复 |
| 120 | 分类逐项结果、改变完成顺序和重试集合，检查副作用次数 | HTTP 200 不代表全部成功；稳定 ID 不等于顺序保证；永久失败不盲目重试 |

## 实现与协作边界

`src/components/architecture-lab/lesson111` 至 `lesson120` 各自包含 `index.tsx`、`model.ts`、`style.css`，默认导出实验，命名导出 `Help({mode})`。沿用 `ArchitectureChapterLab` 的按题懒加载。仅将现有实验和帮助入口范围扩展到 120。

十题按题拆分独立代理任务。运行时创建第四个子代理返回 `agent thread limit reached`，因此复用三个子代理分批承接十题，各任务保持独立文件范围。主代理负责入口接入、整章测试、视觉复核与集成修复。保留 101–110 及其他既有未提交工作，不改变题干、正式测评、编辑器、决策记录和后端存储协议。
