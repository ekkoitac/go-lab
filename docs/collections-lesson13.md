# 第13题：共享底层数组

依据《学习-知识点教学中的交互与呈现方式》，目标是让学习者把局部索引换算到底层格，并解释共享写入和复制隔离的差别。

- 动手观察：通过 low/high 重建窗口、直接赋值、分配并 copy、选择写入窗口/索引/整数改变真实模型。先预测 prices 是否变化并写理由，再执行并查看前后数组与地址映射。历史保留支持回退，重置恢复基线。空窗口可建立但不可索引；同值写入解释“共享但数值不变”。
- 举例子：选择共用货架或复制货架，更换促销盒子会传播到对应观察窗口。
- 画图：选择截取起点和存储关系，点击局部索引追踪到 A/B 的具体格，多表示联动。
- 拆步骤：共享写入、分配复制、隔离写入的单步执行，强调事后 copy 不能撤销既有污染。
- 让我试试：新传感器数组和偏移，独立提交结果与理由后展示推导。数据不写入正式成绩；练习之前不在 DOM 状态里泄露结果。

模型仅包括 []int、双下标截取和独立分配 copy。数组编号和格偏移是抽象地址。复制包含引用的元素仍是浅复制；copy 到已有共享目标不会自动隔离。append、真实字节大小、分配器和并发均不在模型范围。

键盘使用原生 button/select/input/textarea，焦点可见；320/390px 布局自动换行；支持减弱动画。测试包括别名写入、双向隔离、长度和容量、空窗口、同值写入、事后复制及迁移情境。浏览器测试覆盖预测门禁、键盘执行、回退、独立复制、各帮助交互、学习记录隔离与窄屏。
