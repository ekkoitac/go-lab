# 151–160：稳定性与故障隔离实验

本轮按《学习-知识点教学中的交互与呈现方式》重做动手观察和四种帮助。每题由独立 subagent 负责模型、视图和专属测试；共享入口与跨题验证统一集成。

## 教学设计

| 题目 | 核心关系 | 操作与观察重点 |
|---|---|---|
| 151 请求预算 | 时间、取消传播 | 扣除已用和返回预留；单步观察下游预算、父期限与协作取消 |
| 152 支付重试 | 远端事实与本地未知 | 丢失响应后对比新键、稳定键与查询；观察扣款次数和结果可知性 |
| 153 多层重试 | 嵌套调用与乘法放大 | 改各层尝试上限，追踪实际底层调用；对照全失败与提前成功 |
| 154 过载准入 | 槽位、队列、期限 | 请求进入、排队、完成或过期；比较队列容量与有效完成量 |
| 155 熔断 | 状态与证据 | 区分技术故障和业务拒绝；受控半开探测与恢复/回退 |
| 156 资源隔离 | 固定总预算下的资源竞争 | 分配订单/报表份额；观察隔离收益与闲置、排队代价 |
| 157 降级契约 | HTTP状态与业务事实 | 改变业务和故障证据，检验可识别降级与支付未知的边界 |
| 158 优雅退出 | 生命周期与等待责任 | 安排停止接收、在途排空、取消、等待和资源释放，追踪未完成工作 |
| 159 探针语义 | 健康证据与控制动作 | 注入依赖故障或进程故障，对照撤流、重启和启动保护 |
| 160 恢复放量 | 冷态容量、资源竞争、反馈控制 | 分配预热与在线流量，基于观测逐级放量或回退 |

## 共同边界

- “举例子”用于可操作的情境对照，“画图”展示和追踪有语义的关系，“拆步骤”改变实际模型状态，“让我试试”在揭晓前保留学习者的预测和理由。
- 帮助与主实验使用独立 React 状态；帮助探索不修改 Go 编辑器或决策草稿。
- 模拟均为明确简化的教学模型；指标不声称是实际压测数据，也不把揭晓后的练习当作正式独立掌握。
- 保留现有正式题目、评分、运行接口、学习记录和其他章节改动。
- 单题实现和设计见同目录 `resilience-lesson151.md` 至 `resilience-lesson160.md`。
