# 第 3 题：整数转换与溢出

学习目标：用低 8 位解释变窄结果，区分运行时转换与常量可表示性，并在转换前拒绝越界数量。

- 动手观察：输入 -32768..32767 的整数，选直接转换、转换前检查、转换后检查或常量编译；先提交结果与理由，再单步观察检查、截断、发送。16 位输入与 8 位输出联动，支持回退、重置和相同输入四方案对照。
- 例子：操作完整圈数与圈内位置，发现不同累计数可以具有相同的 256 刻度计数盘位置。
- 图解：翻转 16 位位权格，观察高位与低位对 uint8 输出的不同影响。此图明确使用无符号位串，与主实验有符号 int16 输入解释分开。
- 分步：把校验闸门在转换前后移动，逐步追踪它实际检查的值，验证修复是否阻止错误发送。
- 迁移：自行构造与 17 转成相同字节的越界整数，提交推导后验证反例。

帮助内部操作只产生本地辅助反馈，不提交正式作答或掌握成绩；打开帮助仍沿用应用已有的求助记录机制。核心模型是整数转换规则的教学模拟，非 Go 解释器。输入源范围固定；不模拟浮点、机器字长或一般溢出检测。
