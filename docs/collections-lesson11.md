# 第 11 题：数组复制
依据用户指定的《学习-知识点教学中的交互与呈现方式》设计，分开呈现、交互和学习证据。
- 学习目标：判断数组值与数组指针参数写入的存储目标；理解数组复制不递归复制指针对象。
- 主实验：可调三格整数、扣减索引与数量、形参类型；进入函数 → 预测并写入 → 返回。存储格、代码、访问路径同步，回退恢复真实前态，重置恢复基线。
- example：操纵原表和复印件，自选复制时机，观察值快照。
- diagram：对照复制指针数组后解引用写入与替换地址槽，关系图随实际语义更新。
- steps：交换复制和修改语句，逐条执行/回退，发现时间顺序如何影响副本。
- try：四元素排班数组的新任务，提交数值与理由后才揭示运行结果。新情境改变初值与值/指针参数。仅记录局部练习状态，不写掌握记录。
- 边界：顺序执行整数数组，逻辑存储标识不代表真实地址或栈堆分配；负库存允许作为整数算术。长度参与数组类型，复制指针不复制对象。
- 验证：纯模型覆盖值/指针、回退、无变化操作、越界拒绝、引用边界和语句次序；浏览器测试覆盖预测门槛、状态反馈、回退、对照、四种帮助和窄屏。
