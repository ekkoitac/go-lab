# 第 183 题：SSRF 目的地与实际连接

学习目标：区分合作方配置、初次 DNS 解析、实际拨号、重定向后的第二跳和响应资源边界。揭露“初查公网，所以后续连接必然公网”的误解。

动手观察采用状态路径、多视图联动、预测验证、单步回退和诊断修复。输入只有三个合作方 ID；模型使用符号 P/I，无实际联网。学习者先提交结果与理由，再推进确定性步骤；变化直接体现在地址、连接历史和读取指标上。可改变 DNS、重定向和响应情境，对照同样输入下薄弱策略与当前策略的最终结果。配置变化清空预测和执行状态，避免复用旧预测。

四种帮助：快递转送类比让出口检查影响实际路线；关联图选择节点并单步追踪解析与拨号的关系；步骤帮助允许键盘按钮重新排列客户端计划并检验顺序；新情境用图片服务的字节边界和总截止时间检验迁移，须先给预测理由。帮助不调用进度、attempt 或 reveal，也不共享主实验状态。

限制：没有真实 DNS/IP 分类、代理、TLS 实现。模型假定 TLS 成功和无隐式代理；真实 SSRF 控制需要地址族、DNS、代理、TLS、出口和跳数的集成测试。读取按恒定速率模拟，字节指标代表已接受的响应载荷；不模拟真实客户端为探测超限而读取的额外字节。

接口：default Lesson183Lab()；Lesson183Help({mode: 'example'|'diagram'|'steps'|'try'})。
根节点 security-lab-183 / security-help-183，执行状态 live-model 的 data-state，步骤按钮带 data-security-action。
