# 第189题：双层配额实验

学习目标：解释全局4与单租户2的交集，验证申请的共同成败、释放幂等性，并区分配额、队列、公平调度和多副本总预算。

动手观察让学员给同一组任务选择提交A/B、完成或取消任务编号；在执行前提交两种策略的运行数预测及理由。两组资源槽、租户计数、任务生命周期和逻辑时间同步更新，反馈保留预测并给出实际差异。历史操作可回退重置。被拒绝的任务不会自动排队；对已完成或已拒绝任务释放均不减少计数。

四帮助分别提供工作室领桌/退桌类比、租户选择与占用关联高亮、可回退的失败申请及重复释放重放、多副本扩容后的独立数量预测。所有内容为探索与反馈，不写学习进度、测验或掌握记录。

模型明确限定为单线程、原子状态转换。UI记录完成协议所需任务身份，可观察重复释放保护；真实并发需同步及可靠生命周期协议。数量上界不保证长期公平、成本公平或跨实例总量。

验证：tests/security-lesson189.test.ts 检查噪声租户隔离、失败不泄漏、释放幂等、回退分支及1500步不变量。tests/browser/security-lesson189.spec.ts 检查预测门槛、双策略、取消/重复操作、回退重置与320px布局。
