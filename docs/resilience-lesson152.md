# 第 152 题：支付超时与安全重试

目标：区分远端扣款事实与调用方局部认知；解释稳定幂等键还需要服务端去重、相同内容、有效保留期、可重试错误与预算。

依据用户指定的《学习-知识点教学中的交互与呈现方式》：采用角色体验、单步执行、反事实分叉、诊断修复与证据推理，呈现为双泳道因果关系与操作日志。流程：发送 → 远端扣款 → 丢失响应 → 本地未知 → 换新键制造重复 → 回退 → 原键重试或查询修复。参数变动保留已发生事实；回退与重置是教学操作，不是退款。

四种帮助分别使用柜台票号对照、请求边与响应边丢包干预、修复操作序列、隔天保留期失效的迁移预测。迁移题先记录选择和文字理由，再单独揭晓；不调用进度/成绩 API，文字理由不自动判分。

模型边界：请求 100 ms，重试退避另 100 ms；最多尝试含首次；查询需要 100 ms。没有真实支付、退款、网络或后台核对。查询按订单找到已完成支付；预算耗尽保留未知并交独立核对。自动重试拒绝过期记录和内容冲突，不声称稳定键永久有效。

验证：模型单测检查响应丢失、不变性、重复扣款、同键修复、查询、四类拦截、预算边界与重复丢包。专属浏览器用例覆盖键盘发送、构造失败后回退修复、保留期与内容冲突、390px/reduced-motion 及先提交后揭晓；浏览器由主任务集中执行。
