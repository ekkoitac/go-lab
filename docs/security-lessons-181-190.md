每题四个帮助模式分别提供具象例子、关系图、分步过程和新情境练习。练习记录仅存在组件状态，不冒充正式独立掌握证据。既有 `/help` 记录机制保留。

模型均为显式简化的本地教学模拟，不访问外部网络、不执行用户命令、不生成真实令牌、不扫描真实依赖、不写真实审计系统。
