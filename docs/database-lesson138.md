# 第 138 题：滚动字段迁移

学习目标：根据新旧代码的实际列依赖、并发写和回滚承诺，判断扩展、回填、切读与收缩的条件；能构造旧快照覆盖新写的反例，并解释条件更新为何跳过。

呈现形式为双列数据卡、实例读路径、带版本的回填快照和关系图；交互为动作调度、预测加理由、并发干预、回退及修复。每次执行都调用纯模型，反馈保留预测、原理由、实际结果与状态证据。

模型明确：旧版本只写 display_name，靠显式数据库触发器在同一事务同步 full_name；新版双写是一个事务。触发器不回填已有数据。回填先读取旧值及行版本，提交时同时检查版本不变和新列为空，避免覆盖并发写。若无同步桥梁则阻止安全回填。校验比较两列与最新业务值。生产中的触发器设计、覆盖所有写者、全量扫描、限速、断点和 DDL 锁并未模拟。

独立 contract 需切读、旧实例归零、关闭回滚窗口及最新校验同时满足，并将新版本写路径切为仅写新列。直接删列会破坏旧读与兼容双写；应用回滚不会恢复列。教学回退是时间回放，不作为实际数据库回滚能力。

帮助：example 对照条件回填与盲目回填；diagram 显示实例到列的读依赖和旧写同步边；steps 逐步运行真实模型；try 以员工目录和仍开放的回滚窗口改变起始条件。全部练习和帮助不计成绩。

验证：tests/database-lesson138.test.ts 覆盖旧写桥梁、并发新旧写、盲写覆盖、校验、完整收缩门槛、回滚及不可变历史。布局使用隔离 db138 样式，小屏和窄帮助栏单列，所有操作可键盘完成。
