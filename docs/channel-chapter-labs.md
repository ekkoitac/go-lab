# 第 6 章：可构造的 Channel 与取消实验

范围：基础课程第 51–60 课。课程 ID、题目、答案、进度版本和数据库格式保持兼容。

## 操作与验收

| 课 | 可以构造的实验 | 应观察到的机制 |
| --- | --- | --- |
| 51 | 同一个或不同 goroutine；先发送或先接收；单独完成业务 | 阻塞、会合、业务完成是不同事件 |
| 52 | 设置容量 0–5；连续发送；接收；由协调者关闭 | 队首出队、待发值补位、背压、关闭唤醒 |
| 53 | 两个生产者分别发送和结束；提前关闭或协调关闭 | 局部结束不代表全局结束，过早关闭与重复关闭会 panic |
| 54 | 预置有效数据 0、7；自由安排关闭和接收 | 有效零值的 ok=true；关闭排空后每次都是 0、false |
| 55 | 向输入 B 放数据；关闭、禁用输入；直接读 nil；设置全部结束检查 | 关闭通道持续就绪；nil 分支禁用；直接读取 nil 永久等待 |
| 56 | 在相同起点选择结果或取消；重建为未就绪状态后制造就绪 | 多个就绪分支都可选，没有源码顺序优先级；Done 是通知而非整数数据 |
| 57 | 保留或移除 default；逐轮执行；输入消息或取消 | default 空转计数与阻塞状态；数据和取消唤醒 |
| 58 | 任务是否检查取消；两个任务分别推进与清理 | cancel 通知、观察 Done、释放资源、退出回执分离 |
| 59 | 设置缓冲；下游提前退出；普通发送或发送同时监听取消 | 缓冲只能延迟堵塞；取消必须参与阻塞点；退出需确认清理 |
| 60 | 分别设置 worker 数和队列容量；指定领取与完成顺序；关闭并排空 | 并发与排队独立受限；完成顺序可不同；worker 读完后才能退出 |

## 动画与回退

- 使用同版本 `remotion` 和 `@remotion/player`，按需加载第 6 章实验。
- 操作先通过纯状态转换生成记录，Remotion 从该次操作的前后状态生成动画。
- 动画分为操作前、通信过程、操作后三个阶段；数据移动和强调均由 `useCurrentFrame()` 驱动。
- 可以重播、暂停、拖动本步动画；操作时间线可回退、前进或跳转。回退后执行新操作会替换后续路径。
- 手动跳转操作时间线停在该步结束状态。系统要求减少动态效果时，默认关闭操作后播放。
- 小屏按两列角色与纵向通道排布，不截掉接收方或依赖横向滚动。
- 实验配置变化会重建实验；历史最多 200 步。实验状态不写入学习成绩，也不改写右侧代码。

## 模型边界

这是由学习者调度的教学模型，不是完整 Go 解释器，也不提供 CPU、吞吐或公平性的性能预测。

`select` 按钮用于枚举合法分支，不意味着实际 Go 可手动指定选择。阻塞队列用本模型的到达顺序演示；不把这一顺序作为所有 Go 调度的保证。未恢复的 panic 终止当前实验，必须回退或重置后继续。

右侧编辑器仍执行真实 Go；它与实验操作台独立，不根据任意编辑后的源码自动生成动画。

## 验证入口

- `npm run build`：类型、课程完整性与生产构建。

- 原 `observation.spec.ts` 的第 6 章预设快照遍历由上述状态实验测试替代，其余章节仍保留原测试。
- 浏览器测试使用独立端口和 `.runtime` 测试数据库；不读取或覆盖正常学习记录。
