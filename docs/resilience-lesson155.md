# 第 155 题：熔断证据与受控恢复

学习目标：区分业务拒绝与依赖故障，解释 Closed / Open / Half-open 的事件和守卫条件，验证冷却与成功证据不是一回事。

动手观察采用可操作状态机：提交请求、注入返回结果、推进模拟时钟。配置错误分类、冷却时长和探测并发上限后从基线重演；每一步有前后状态、在途请求、故障计数、触达与降级量。回退后可选择不同事件形成反事实分支。

四种帮助：
- example：完全相同请求序列，对照两种错误分类规则。
- diagram：选择状态关联变量与守卫条件；事件时间线改变真实模型快照。
- steps：真实状态机逐事件重放两次故障、冷却、有界探测、恢复。
- try：新情境中先提交状态预测与理由，再单独运行揭晓；结果不写入掌握成绩。

边界：单实例、连续故障阈值 2、恢复成功阈值 2；业务拒绝是中性证据。旧状态周期的迟到结果不改变当前决策。时间与结果均由学习者显式注入。未模拟超时取消、统计窗口、跨实例探测错峰或真实负载压垮；并发上限只是准入边界，不是容量安全证明。

验证：专属模型测试覆盖分类、打开阈值、冷却边界、半开并发、成功关闭、失败重开、迟到结果隔离与快照不变性。浏览器用例覆盖事件推进、回退、配置重置、390px 布局和键盘操作。样式局限于 .r155，支持 reduced-motion。
