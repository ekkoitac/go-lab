# 第 81–90 题：测试与工具链交互重做

依据：`E:\ekko-lib\ekko-lib\临时\学习-知识点教学中的交互与呈现方式.md`。

每题由独立子 agent 实现模型、观察台、四种帮助和模型测试；公共入口由主任务接入。

## 教学设计

| 题号 | 理解目标 | 呈现与可操作任务 |
|---|---|---|
| 81 | 测试预期来自规格，复制实现会复制缺陷 | 边界输入与双判定表；预测、切换预期来源、修复条件 |
| 82 | 用例类别比表格行数重要 | 用例表与类别覆盖；构建用例、切换公式与校验、找遗漏边界 |
| 83 | 独立循环变量不等于独立可变对象 | 引用关系与执行轨迹；调度两测试、比较共享与独立 fixture |
| 84 | 控制时钟才能复现精确边界 | 时间轴与有效区间；移动时刻、比较边界规则与延迟干预 |
| 85 | 最终值、数据竞争和执行路径证据不同 | 访问轨迹与检测范围；构造交错、切换保护方式与路径覆盖 |
| 86 | 模糊测试依赖有效性质与输入策略 | 字节格与反例序列；输入 Unicode、选择切割单位、探索及缩减反例 |
| 87 | 测量范围和结果消费决定基准的解释 | 计时阶段与指标；调整准备成本、计时范围和结果保留 |
| 88 | 执行代码与验证行为是两种证据 | 执行高亮与断言矩阵；加入负数用例、补断言、修复实现 |
| 89 | 格式、静态检查、行为测试各有职责 | 检查流水线与诊断；配置检查、注入缺陷、修复并重验 |
| 90 | 模块要求、工具链选择、环境记录共同影响复现 | 配置和选择路径；改变模块/本机版本及策略、比较构建证据 |

## 共同边界

- 每个视图说明模型假设。演示的计时、调度、race/fuzz/工具链结果不冒充真实执行。
- 举例子、画图、拆步骤、让我试试分别服务类比、关系、因果追踪和新条件检验。
- 学习者先表达预测与依据，再揭示反馈；配置变化后清理过期结果。
- 帮助内练习与主观察台状态隔离，不调用正式作答、答案揭示或成绩接口。
- 每题 CSS 限定本题范围，提供可访问控件及移动端布局；不依赖动画传递唯一信息。
- 原有代码编辑器、正式题目、学习记录与后端协议不作本次重写。
