# 第 34 题：defer 参数何时求值

| 设计项 | 实现 |
|---|---|
| 学习目标 | 区分登记时求值与退出时执行；识别有参闭包仍保存参数副本 |
| 典型误解 | 延迟调用意味着所有表达式都延迟；闭包必然读最终值 |
| 核心关系 | 时间、因果和变量/参数副本之间的区别 |
| 呈现形式 | 五阶段时间线、局部变量/延迟记录/输出三列图与代码 |
| 动手观察 | 调初值和终值，切换三种写法，单步/回退/重置 |
| example | 相同输入三种写法同步对照，观察输出和保存方式 |
| diagram | 点击数据来源卡，操作活变量修改和退出，追踪值或变量引用路径 |
| steps | 扮演执行器，在每一步确认下次读取发生的时点 |
| try | 新输入和新写法先提交输出与理由，再揭晓，下一题重置预测 |
| 反馈 | 保存值、活变量值、输出值及发生变化的具体时点 |
| 独立验证边界 | 帮助中的辅助迁移练习不计课程成绩；理由仅自查 |
| 模型边界 | 普通 int、单 defer、同一局部变量；不涵盖指针实参或多个 defer |
| 可访问性 | 原生键盘表单、aria-live、窄屏堆叠、减少动画 |
