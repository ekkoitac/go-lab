# 第 11–20 题：数组、切片与 map 交互重做

设计依据：用户指定的《学习：知识点教学中的交互与呈现方式》。以学习目标选择表示和交互，保持操作、状态变化和原因可追踪。

每题由一个独立 subagent 实现；根代理负责页面接入和跨题验证。各题默认导出动手观察，Help 分别实现举例子、画图、拆步骤、让我试试，不在帮助里重复挂载整个实验。

| 题号 | 学习关系 | 主要可观察证据 |
|---|---|---|
| 11 | 数组值复制、指针访问 | 修改形参后原数组是否改变；引用元素的浅复制边界 |
| 12 | 起点、长度、容量 | 索引与重新切片的合法边界；扩展后零值与有效数据的区别 |
| 13 | 切片描述符和底层别名 | 两个索引命中同一格；显式复制解除共享 |
| 14 | append 分配条件 | 同一追加在不同容量下的数组归属；限制容量的作用范围 |
| 15 | 函数参数与返回描述符 | 元素可能共享，而调用者长度必须通过接收返回值更新 |
| 16 | copy 的长度约束 | min(len(dst), len(src))；部分复制、零长度和重叠复制 |
| 17 | 对象可达性 | 限制容量不解除引用，复制且去掉其他引用才具备回收条件 |
| 18 | nil 与非 nil 空切片 | 同样长度对应不同 JSON 表示；协议由边界约定决定 |
| 19 | map 零值和存在性 | value 相同而 ok 不同；查询、删除、写入的可见结果 |
| 20 | 遍历顺序和同步 | 排序建立输出顺序，共同同步约定另行保护读写 |

## 实现边界

- 仅接管 11–20 题的动手观察和四类帮助，保留原课程题目、代码编辑器、正式测验及进度接口。
- 纯模型服务于教学；模拟存储编号、回收资格、合法遍历示例不冒充运行时地址、实际 GC 时刻或概率分布。
- 帮助沿用已有求助记录接口；本地预测和辅助练习不提交正式作答、揭晓或独立掌握记录。
- 每题状态独立；切换帮助不重置主实验。每题 CSS 使用 c 加题号前缀限定。

## 验证入口

- 纯模型：tests/collections-lesson11.test.ts 至 collections-lesson20.test.ts。
- 每题交互：tests/browser/collections-lesson11.spec.ts 至 collections-lesson20.spec.ts。
- 跨题整合：tests/browser/collections-lessons.spec.ts，覆盖四种帮助差异、状态隔离、正式作答写入隔离、320/390 像素布局和减少动画设置。
- 根代理另用真实 Go 核对复制、索引、append、copy、引用隔离、JSON 和 map 核心语义。
- E2E 采用独立端口及 .runtime 下测试数据，不使用正式学习记录。

各题具体任务、模型假设和反馈设计参见同目录 collections-lessonNN.md。
