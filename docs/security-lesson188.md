# 第 188 题：供应链证据工作台

按照用户指定《学习-知识点教学中的交互与呈现方式》区分学习目标、呈现形式和交互方式。

- 目标：区分完整性、已知漏洞可达性、来源可信度与交付决策。校验和匹配不是安全证明。
- 呈现：纵向调用关系图、构建参数、分步证据和交付判断联动；不使用笼统安全分数。
- 交互：改版本、断调用边、生产/分析标签反事实、先预测并解释再单步、改条件重算、回退与重置。
- 模型：虚构 decoder v1.0 和 LAB-188-A；v1.1 仅修复该教学公告。只有构建记录存在且分析/生产标签一致时才判断可达性。缺失证据为 unknown，不冒充不可达。未运行真实 govulncheck。
- 交付：校验不符或漏洞可达阻断；来源、审查、测试、回退证据不足则暂缓；齐全只支持受控发布评审，不承诺零风险。
- 帮助：封条/召回双证据类比，调用边关联图，按序组装交付证据，生产标签不一致/新发布者迁移预测。所有模式都有实际控件与因果反馈。
- 不写 progress、attempt 或 reveal；帮助和本地新情境不计入独立掌握。
- 可访问性：原生表单与按钮、可见焦点、中文标签、窄屏单列；无 SVG 裁切问题。
