# Go 100 Lab

两条独立学习路径、共 200 课的本地交互课程：Go 入门 100 题，以及 Go 架构师 100 题。面向会编程、正在学习 Go 的人，按照「预测 → 操作观察 → 理解机制 → 修复 → 换场景检验」推进。

## 启动

需要 **Node.js 24.13+**；执行代码练习还需要 **Go 1.26+**，决策课可在未安装 Go 时学习。本项目已在 Windows / Go 1.26.1 验证。

```powershell
cd 'E:\Coding\Code项目\ekkoitac\go-100-lab'
npm install
npm run dev
```

打开 http://127.0.0.1:4317 。前端与执行服务同时启动；按 Ctrl+C 正常关闭。服务端端口为 4318，两者都只监听本机。端口被占用时先关闭旧实例。

生产运行：

```powershell
npm run build
npm start
```

打开 http://127.0.0.1:4318 。保留项目依赖（包括 tsx），不要使用 `npm install --omit=dev`。页面、编辑器、插图、课程、字体回退均为本地资源；安装完成后无模型 API、CDN 或外部数据库依赖。官方资料链接需联网阅读。

若 Go 不在 PATH，可设置 `$env:GO100_GO_PATH='E:\Coding\Golang\bin\go.exe'` 后启动。本机当前 C 编译器不满足 race runtime 条件，Race 按钮会禁用并给出原因；普通 Go 运行、测试与基准不受影响。不会自动升级或下载 Go 工具链。Go 1.27 的差异以课程扩展说明呈现。

## 怎么学习

- 课程地图可切换两条路径，各包含 10 个模块、100 课；搜索、收藏、复习、进度按当前路径展示，支持直接跳课。
- 桌面侧栏可收起为窄图标栏；章节标题展开课目，课目可直接进入，「查看本章」定位地图列表。多章可同时展开，当前课会高亮并自动定位。
- 搜索支持当前路径的标题、章节名和题号，可清空或重置筛选。从地图进入课程后，返回和浏览器前进／后退会恢复对应路径的地图条件与滚动位置。
- 手机导航以抽屉打开，支持关闭按钮、遮罩和 Esc，关闭后恢复按钮焦点；桌面侧栏收起不会清空代码、决策笔记或实验状态。
- 每课包括 6 个学习环节、6 项题目（含迁移和另一份复测变体）及至少两个条件分支的可逐步实验。代码课提供原始 Go 示例与参考修复；决策课提供可恢复的决策记录。
- 「举例子 / 画图 / 拆步骤 / 让我试试」随时可用。预测题在提交前隐藏解答；选择题、填空、排序、多选、匹配、定位题都有对应反馈。
- 在代码区修改后点「运行」观察真实输出；「测试」检查目标行为；「基准」执行 Go benchmark。参考修复会记录已查看答案。
- 「动手观察」把自由操作台与分步图解分开：操作台按自己的按钮改变输入；图解提供具体步骤名称与下一步操作预告，可用鼠标或键盘跳转、单步、回退、播放、重置，并对比两个条件的末步结果。每步会列出状态前后变化；数值不变也会说明已执行及原因。重复点击当前条件保留进度，切换另一条件才从头开始。Read 处理完成后可重新处理，关闭通道后的连续接收会显示完成次数。手动操作会暂停播放，切换条件会回到第一步。绿色表示关注项，橙色边框表示新增或更新；只有明确的引用关系才画箭头。窄屏下状态卡片重排，引用关系图可横向滚动。
- 动态图是**教学模型**。代码任意编辑后，右侧实际输出来自 Go，图形仍表示课程预设模型。并发模拟展示一种可能的执行安排，不代表唯一调度；模型耗时不作为 Go 实测性能。
- 数据库课程使用明确标注的教学 database/sql 驱动，演示 API 和资源生命周期，不模拟完整数据库引擎。HTTP 实验通过本地 httptest 实现。
- 浏览完成、练习通过、独立迁移测验通过分别统计。提示、答案揭示和同题重复提交不会新增独立证据；独立通过只说明该次变体判断正确，不等于已全面掌握语言。
- 费曼复述采用自评清单，不自动判定理解。复习安排为 1、3、7、14 天；答错回到一天。两份题都练过后，再次作答仍记为复习练习。

## 数据与恢复

- `data/learning.sqlite`：课程步骤、版本、作答、求助、草稿、收藏、复习和运行记录。
- `.runtime/runs/`：每次执行的临时工作目录，结束后仅清理该次目录。
- 编辑器每次输入立即写入浏览器恢复缓存，然后同步 SQLite；关闭或刷新后可恢复未同步内容。
- 侧栏收起偏好与章节展开状态保存在浏览器本地；地图浏览上下文保存在当前标签页会话。这些界面设置不进入学习备份，存储不可用时仍可在当前页面操作。
- 在「学习记录」导出 JSON 备份；恢复时先验证全份内容，替换涉及课程，并归档旧记录。导出也包含历史归档。不要删除 `data/` 来清理执行缓存。
- 内容版本更新保留旧证据与草稿，旧结果不自动计入新题通过。服务启动时将未完成运行标记为中断。
- 测试可设置 `GO100_DATA_DIR` 指向独立数据目录，避免影响个人学习记录。备份仅恢复学习内容，不恢复运行中的进程。

## 执行边界

这是个人本机代码执行器，**不是恶意代码安全沙箱**。提交的 Go 代码以当前用户身份运行，可以访问本机资源；请只执行自己编写或信任的代码，不对公网开放服务。

服务验证 Host、Origin、Fetch Metadata 和会话令牌，文件名和运行参数由课程模板控制。默认串行运行；编译上限 60 秒，程序运行 5 秒，测试/基准 15 秒，合计输出 256 KiB。取消、超时和输出超限会终止对应进程树。关闭页面或切换课程时当前运行会取消；结果与学习记录保留。

配置禁用 Go 依赖代理、工作区继承、自动工具链下载。课程本身只使用标准库；没有额外 Go 包下载步骤。独立测试验证 API 访问边界、中文输出截断、错误与进程回收。

## 验证命令

```powershell
npm run typecheck
npm run check:content
npm test
npm run test:go
npm run test:e2e
npm run build
```

- 内容检查：200 个稳定 ID、1,200 道题、各阶段、来源、答案映射、至少 400 个条件场景，以及新增 100 课的决策约束、方案取舍和 Mermaid 图。
- `test:go`：通过应用执行器实际验证全部代码课的原始程序、参考实现和行为测试；报告代码课与决策课数量，决策课不计入 Go 验证。可用 `npm run test:go -- 14 24 52` 定向核对；`--test-only` 仅核对修复测试。
- `test:e2e`：使用本机 Chrome，检查原 100 课全部 200 个分支的每一帧，以及新增 100 课的全部 Mermaid 图与分支状态变化、双路径导航与决策草稿恢复、图中文字边界、全部课程的手机布局、播放与回退、专项模型、真实 Go 测试和记录恢复。若未安装 Chrome，可安装浏览器或调整 Playwright 配置。
- `scripts/verify-part1.ts`、`verify-part2.ts`、`verify-part3.ts` 是内容作者的独立样例校验；正式统一验收使用上述命令。
- 学习规则/API 测试使用内存或独立临时数据库；浏览器测试自动启动使用 .runtime/e2e-data 的独立服务，端口为 14317/14318，不会占用开发服务的 4317/4318。正常开发端口也可用 GO100_WEB_PORT / GO100_API_PORT 显式指定，仍只监听本机并验证对应 Host / Origin。

## 结构

- `src/content/module01.ts` 至 `module10.ts`：原入门课程，保持 ID 1–100 与原内容版本。
- `src/content/architecture/`：新增架构案例模块，使用 ID 101–200，按模块懒加载。
- `src/components/`：代码编辑器、测验和动态实验。
- `src/learning.ts`：判题、独立证据与复习间隔规则。
- `server/`：本机 API、SQLite、Go 运行与终止。
- `tests/`：学习、API、真实执行与浏览器验收。

认知设计依据用户提供的「人类认知协议」：分层呈现、动态视觉、具体情境与类比、即时反馈、自主求助与节奏控制。所有图形均为项目原生 SVG/DOM，无外部图片请求。

## Go 架构师 100 题

在页面顶部选择「Go 架构师 100 题」。十个模块覆盖系统边界、API、并发治理、数据库、缓存消息、稳定性、容量、可观测性、安全与交付；这是实战选题集合，不是统计频率排名。

新增课程包含 **38 课代码实践、62 课决策实践**。每课先给业务场景与约束，再预测、观察实验、比较方案，并在约束变化后重新判断。方案比较包含收益、代价、适用条件、决策口诀和失效边界。开放决策与费曼记录采用自评，不自动算作独立掌握。

架构图、流程图、时序图和状态图依照 [Mermaid 官方接入文档](https://mermaid.js.org/config/usage.html)，由本地 Mermaid 严格模式渲染，可放大阅读，失败时保留文字图解并支持重试。资源条图按同名指标在本课所有分支使用同一比例，模型数字不代表实测性能。预测阶段不预先展示推荐方案图；求助仍记入辅助练习。

设计类课程没有代码编辑器，不需要 Go 即可学习；机制类课程继续运行本机 Go。数据库、消息、缓存及发布实验不要求安装外部中间件，模型限制在课程中说明。模型验证不能替代真实系统的集成与生产验证。

两条路径分别记住最近学习位置。决策笔记每次输入即写入本地恢复缓存，再同步 SQLite，和本课费曼记录共用。导出备份包含两条路径的全部记录；仍可导入旧版备份，未涉及的课程保持原样，替换前记录保留为历史。原课程、代码草稿键、学习证据与数据库均不重建。

并行验收时可设置 `GO100_E2E_WEB_PORT`、`GO100_E2E_API_PORT`、`GO100_E2E_DATA_DIR` 和 `GO100_E2E_OUTPUT_DIR`，隔离服务、数据库和测试产物。`test:go -- --workers=3` 可加速验收（最多 4 个独立执行器；应用运行限制保持不变）。

生产冒烟执行 `node scripts/production-smoke.mjs`，使用独立端口 26318 和 `.runtime/architecture-production-smoke` 数据目录，检查本地资源、图解、双路径、缺少 Go 的决策学习及新旧备份恢复；可通过 `GO100_PRODUCTION_SMOKE_PORT` 调整端口。

全课程浏览器验收默认保留失败截图，不连续录制所有 SVG 帧；排查单个失败时可运行 `npm run test:e2e -- --grep "用例名称" --trace retain-on-failure` 获取完整跟踪。
